# mr.x — Engineering Audit / Hardening — 2026-09-24

## Changes applied
- Bounded Offline mutation queue: 500 entries and 512 KiB per queued JSON body.
- Failed Offline sync attempts are counted and capped at 8 attempts; permanently failing entries remain stored instead of being silently deleted or retried forever.
- Media Offline queue rejects a failed enqueue and removes the local file instead of reporting false success.
- Service routing now matches the configured HTTPS origin structurally instead of relying on raw string prefixes.
- Configured service origins reject query strings, fragments, userinfo, and invalid ports.
- App version bumped to 2.11.0 / versionCode 25.

## Verification
All existing static/security/regression/offline/multiserver/service-isolation/native-only checks pass after the edits. Python load-test helpers compile successfully.

## Build/runtime status
The source is **not yet proven as a built/running APK in this environment**. The environment currently lacks Gradle, the Gradle Wrapper JAR, Android SDK command-line tools, platform-tools/adb, Build Tools 36.0.0, and Android platform 36. The build scripts fail closed rather than fabricating an APK.

AGP 9.4.x requires Gradle 9.6.0 or newer; the project is pinned to Gradle 9.7.1, which satisfies that requirement. Android's current documentation lists Build Tools 36.0.0 for AGP 9.4.0.
